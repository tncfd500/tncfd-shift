## 最新功能亮點 (2026-10-16 更新)

### 1. 全面解鎖：任何人進站皆可自由修改
- 移除所有密碼輸入限制，任何同仁只要透過線上網址開啟，一進來就直接處於**可編輯模式**。
- 可直接按住滑鼠拖曳同仁卡片進行跨分隊調任、同分隊排班順序調整。
- 點擊任意同仁的「職稱」或「姓名」即可直接行內修改，點擊卡片彈窗可進行更詳細的人員狀態設定。

### 2. 附註說明欄（Memo Banner）支援線上即時修改
- 頂部的金黃色「📌 附註說明欄」改為可點擊編輯。
- 點擊附註文字或點擊「✏️ 修改附註」按鈕，即可輸入自訂的大隊長交代事項、跨分隊支援註記、調度備忘錄等。
- 修改後立即自動儲存並同步。

### 3. KPI 統計欄位與下方填寫資料 100% 動態連動
頂部的五大數據卡片已完全改為**即時動態計算**，與下方各分隊及人員資料全面連動：
- **編制總人數**：即時等於「警消現員數 + 替代役男 + 事務助理」，動態加總。
- **警消現員數**：動態統計所有職稱非助理、非役男的外勤警消人員，隨新增、刪除、調動或改職稱秒級自動更新。
- **替代役男**：自動加總各分隊卡片上的役男編制數，以及職稱設為「役男/替代役」的人員總數。各分隊卡片上的「役: 1」可直接點擊修改！
- **事務助理**：動態統計職稱包含「事務助理」的行政同仁總數。
- **本次調動/新進**：動態掃描所有人員的備註，只要包含「調入」、「分發」、「特考」、「新進」，人數自動連動更新。
- **各分隊電話與人數微調**：各分隊卡片頂部的電話、0116前人數、0116後人數，皆支援點擊修改！

### 4. 資料保存與匯出機制
- **本機自動儲存**：瀏覽器 `localStorage` 隨時保存最新狀態。
- **匯出 Excel**：點擊「匯出 Excel」可隨時產出包含最新修改內容與附註說明的 Excel 試算表（.xls）。
- **A4 橫式列印**：內建專屬列印 CSS，Ctrl+P 即可列印為標準紙本編制表公文。
