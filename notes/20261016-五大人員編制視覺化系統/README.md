## 最新功能亮點 (2026-10-16 KPI 與表格全員即時雙向連動版)

### 1. ⚡ 全面即時連動計算引擎 (Live Dynamic Recalculation)
無論在「組織卡片檢視」還是「官制編制總表」中，只要下方資料發生任何更動，**頂部 5 大 KPI 數據與表格合計列一秒都不延遲，數字即時動畫跳動更新**：
- **警消現員數**：
  - 動態即時統計所有職稱為外勤警消人員（排除事務助理與役男）。
  - 下方新增/刪除隊員、調動分隊、或將職稱改為助理時，頂部數字與分隊現員數瞬間跳動！
- **替代役男**：
  - 連動各分隊填寫的役男數，以及職稱設為役男的人員。
  - 下方各分隊卡片或表格上的「役男」輸入框只要修改數字，頂部「替代役男」與「編制總人數」立刻同步跳動！
- **事務助理**：
  - 動態連動所有職稱包含事務助理的行政同仁，改動即時重算。
- **本次調動/新進**：
  - 智慧動態掃描所有人員的備註：只要在任何同仁的備註輸入「調入」、「新進」、「分發」、「特考」，頂部「本次調動/新進」數字立刻 +1；清除備註立刻 -1。
- **編制總人數**：
  - 公式：`警消現員數 + 替代役男 + 事務助理`，隨上述四項變動即時動態加總。

### 2. 📋 官制編制總表支援直接輸入與「全大隊合計列」
- 表格內的「0116前」、「0116後」、「役男」、「助理」全面改為**直接行內輸入框**，鍵入數字即刻儲存並連動。
- 表格最底部新增【🔥 全大隊編制合計】總結列，完整加總前/後人數、役男、助理與警消現員。
