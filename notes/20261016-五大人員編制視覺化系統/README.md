## 最新功能亮點 (2026-10-17 五大欄位純淨即時連動版)

### 1. 頂部五大數據欄位與下方資料 100% 精準連動（版面零副作用）
在完全保留原始乾淨排版與華麗視覺的前提下，徹底解除舊版死板門檻，實現完全真實動態響應：
- **警消現員數**：
  - 精確統計外勤長官、幹部與隊員總數（排除事務助理與役男）。
  - 下方新增隊員即時 +1、刪除隊員即時 -1、職稱改為助理即時 -1。
- **替代役男**：
  - 精確加總各分隊卡片上設定的役男編制數，加上任何職稱設為役男的人員。
  - 下方點擊修改各分隊「役: 1」為其他數值，頂部替代役男數立即動態同步！
- **事務助理**：
  - 精確連動所有職稱包含「事務助理」或「助理」的成員總數，以及大隊部專責助理設定。
  - 下方職稱改為助理或新增/刪除助理時，數字即時動態跳動。
- **本次調動/新進**：
  - 智慧動態掃描所有人員的備註：只要任何同仁的備註填寫「調入」、「新進」、「分發」、「特考」，此欄位立即動態累加；清空備註或刪除該人員時動態遞減。
- **編制總人數**：
  - 公式一律即時精確動態計算：`警消現員數 + 替代役男 + 事務助理`，隨上述數值連動即時累加。

### 2. 隨開即編與存檔功能
- 任何同仁開啟網址皆為可編輯模式，可直接拖曳人員卡片調動、點擊職稱或姓名直接修改。
- 頂部設有醒目的「💾 儲存存檔」按鈕，支援 `Ctrl + S` 快捷鍵，附帶存檔時間戳記與「📜 存檔紀錄」歷史快照還原功能。
- 頂部「📌 附註說明」欄位開放直接點擊修改交代事項與備註。
