## 系統特色與功能亮點

### 1. 人員直覺拖曳拉動 (Drag & Drop)
- **跨分隊調動**：滑鼠長按任意同仁卡片（附有 `⠿` 拖曳圖示），直接拉動至目標分隊卡片並放開，即瞬間完成跨分隊人事調動！
- **同分隊排序**：在同一分隊內，可將人員拖曳至其他同仁卡片前後，自由微調編制排班與資歷順序。
- **高亮視覺提示**：拖曳期間滑鼠移至的分隊卡片會發出蔚藍高亮光暈外框，直覺明確。
- **動態重算與自動儲存**：拖曳放開後，來源分隊與目標分隊人數立即動態重算，並自動儲存至本機快取與顯示 Toast 通知。

### 2. 視覺化界面與多檢視模式
- **組織卡片檢視（首選）**：依大隊部、歸仁中隊、安檢小組、大橋高救、永康、鹽行、復興、大灣、歸仁、歸仁高救、保西、仁德、文賢、關廟分隊，依長官/幹部/基層層級階梯化排列，色彩鮮明。
- **官制編制總表**：還原 Excel 官方排版，呈現前後人數、役男、助理及全員對齊名冊。
- **人事調動對照表**：完整整合 Excel 原 Sheet1 之「外縣市調入（20員）」與「113年警察特考四等分發（14員）」名單。
- **人力結構分析**：各分隊編制長條圖與人數對比統計。

### 3. 直覺強大的職稱與姓名修改功能
- **點擊即編輯（行內編輯）**：滑鼠點擊任意同仁的「職稱」或「姓名」，立刻變成輸入框，打完按 Enter 或點旁邊即可自動儲存。
- **詳細彈窗編輯**：點擊人員卡片可編輯姓名、職稱（附常用職稱快捷標籤）、調動分隊、備註（如退離日期、支援註記），亦可刪除人員。
- **新增人員**：點擊右上角或各分隊卡片「➕ 新增人員」按鈕，快速加入編制。

### 4. 資料保存與匯出機制
- **本機自動儲存**：採用瀏覽器 `localStorage`，重新整理或關閉瀏覽器資料絕不遺失。
- **匯出 Excel**：點擊「匯出 Excel」可產生最新編制狀態的 Excel 試算表（.xls）。
- **JSON 備份與載入**：支援一鍵下載 JSON 備份檔，或載入轉移至其他電腦。
- **A4 橫式列印**：內建專屬列印樣式，Ctrl+P 或點擊列印按鈕即可完美輸出官方紙本報表。
