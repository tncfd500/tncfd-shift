## 最新功能亮點 (v1.3 鍵入即時跳動與高亮反饋版)

### 1. 為什麼先前測試覺得「沒有即時變動」？
1. **失焦延遲問題**：舊版必須在輸入框按 Enter 或點擊其他地方「失焦（blur）」後才會觸發重算，在打字輸入當下上方數字完全不動。
2. **門檻限制缺陷**：舊版對調動人數設置了 `Math.max(..., 34)` 固定底線，導致小於 34 時數字被固定不動；且大隊部助理數被既有欄位阻擋累加。
3. **瀏覽器 CDN 快取**：GitHub Pages 與瀏覽器通常會保留快取，未強制刷新（Ctrl+F5）容易看到尚未更新的舊版腳本。

### 2. 本次核心修正重點
- **鍵入即時響應（Live Keystroke Reactivity）**：
  - 在卡片上點擊「職稱」修改為「事務助理」或「役男」，**每按一個鍵（oninput），頂部數字立刻跳動，無需按 Enter 或等待失焦！**
  - 在人員編輯彈窗（Modal）輸入職稱或在備註填寫「調入/特考」，頂部數字隨鍵入即時動態連動。
- **動態跳動光暈動畫（Pulse Feedback）**：數字變動時伴隨微型放大與蔚藍光暈高亮反饋，肉眼即刻清晰可見。
- **直覺的分隊役男與前後人數微調標籤**：
  - 各分隊卡片右上角設有「前: -」、「後: -」、「役: 1」的互動徽章，點擊即可修改分隊役男數，頂部替代役男與編制總人數立即同步跳動！
- **嚴守版面一致性**：完全不更動既有的整體美觀 UI 版面、卡片外觀與操作配置（其他地方零變動）。

## 最新功能亮點 (v1.4 鎖住僅供檢視防誤觸模式)

### 1. 為什麼需要「鎖住，僅供檢視」？
- 網頁已開放給同仁線上瀏覽，若沒有鎖定機制，同仁滑動手機或滑鼠點選時容易意外拖曳人員卡片或誤觸編輯，造成資料非預期變動。

### 2. 鎖定模式核心機制
- **頂部工具列切換鈕**：
  - 預設提供「🔓 編輯中（點擊鎖定）」與「🔒 僅供檢視（已鎖定）」兩種狀態切換。
- **全站鎖定防護（Lockdown Enforcement）**：
  - 鎖定狀態下，全卡片人員禁止拖曳拉動（`draggable=false`）。
  - 禁止點選姓名/職稱彈出編輯視窗。
  - 禁止雙擊行內直接修改文字。
  - 隱藏或停用「+ 新增人員」、「✕ 刪除」、「附註說明修改」等編輯動作。
  - 僅保留切換檢視檢視（卡片、官制、調動、分析）、縮放全螢幕、歷史存檔清單查看與 Excel 匯出功能。
- **狀態持久化**：鎖定狀態自動記錄於本機瀏覽器（`localStorage`），重整頁面依然維持鎖定或解鎖狀態。

## 最新功能亮點 (v1.5 修改後全面自動存檔版)

### 1. 為什麼需要修改後「自動存檔」？
- 過去雖然點擊「💾 儲存存檔」能存入瀏覽器，但使用者在日常調整（例如拖曳換分隊、修改職稱、編輯附註）後若忘記按儲存，容易擔心網頁關閉會遺失進度；且頂部一直顯示「尚未手動存檔」會造成心理不確定性。

### 2. 自動存檔核心機制
- **全事件自動觸發（Seamless Auto-Save Everywhere）**：
  - **人員拖曳調動**：放下卡片的瞬間，立即自動寫入資料庫並更新存檔時間戳記。
  - **行內即時打字**：採用防抖（Debounce 600ms）即時自動儲存，打字一停下即完成存檔。
  - **編輯視窗與增刪**：點擊「確定儲存」或「刪除人員」後，立即自動存檔。
  - **附註說明與人數調整**：修改確認後，立即自動存檔。
  - **關閉頁面保護（beforeunload）**：關閉或重整瀏覽器當下若有未完成的輸入，自動強制寫入儲存。
- **即時視覺狀態燈號（Live Status Dot）**：
  - 頂部存檔徽章具備呼吸燈號：
    - `⚡ 已自動存檔 17:50:30`（綠色平穩燈）
    - `⏳ 自動存檔中...`（琥珀色呼吸閃爍）
    - 手動點擊「💾 儲存存檔」依然保留，提供「✅ 存檔成功！」雙重確認。
- **智能快照防暴衝（Throttled Snapshots）**：
  - 自動存檔同時配合智能頻率限制（重大調動或間隔超過 30 秒自動保留歷史快照），確保「📜 存檔紀錄」依然可以隨時還原至先前的版本，既不丟失資料也不洗版。

## 最新功能亮點 (v1.6 A4 列印 100% 還原 Excel 華麗版格式)

### 1. 為什麼列印要改採 Excel 華麗版格式？
- 原本網頁的列印功能僅直接列印深色網頁版面或簡易清單，無法直接產出如局處公文陳核、主管會議桌上常見的正式 A4 橫向報表；而原始 `1150116五大人員編制_華麗版.xlsx` 是經嚴格規劃的一頁式 A4 橫向官制編制總表，列印時必須完美一致。

### 2. A4 格式完美還原核心特色
- **21 欄位橫向規格嚴格對齊**：
  - 左側區塊：單位與電話、警消0116前、警消0116後、役男、事務助理、合計。
  - 右側官制陣容：大隊長、副大隊長、組長、組員、小隊長、隊員（8~11 欄位）。
  - 外勤分隊採「雙列合併 (rowspan=2)」：第 1 列安排分隊主管與前半部隊員，第 2 列安排後半部隊員（含新進特考、外調、待退異動日期註記）。
- **隨時動態連動最新資料**：
  - 列印表格並非靜態死資料，而是依據使用者線上編輯、人員拖曳調動、姓名職稱修改後的最新 `appData` 即時動態生成，列印永遠反映最新現況。
- **預覽與列印雙模式支援**：
  - **線上預覽**：點擊上方「📋 官制總表」即可在網頁直接查看該 A4 Excel 華麗版表格。
  - **一鍵列印**：點擊「🖨️ 列印 A4」自動套用 `@page { size: A4 landscape; margin: 4mm 6mm; }` 橫向單頁極致列印，徹底隱藏所有網頁按鈕與操作列。
  - **同步升級 Excel 匯出**：點擊「📊 匯出 Excel」時同步輸出該 21 欄位標準格式。
