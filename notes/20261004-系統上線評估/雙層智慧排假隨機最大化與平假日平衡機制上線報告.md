# 雙層智慧排假隨機最大化與平假日平衡機制上線報告

## 1. 功能實作摘要
1. **志願優先核准**：
   - 保留第 1 層管理者 S 型輪次排序與第 2 層同仁個人志願（志願 1、2、3...）核定邏輯。
2. **剩餘空格隨機最大化與平假日平衡分攤**：
   - 介面新增核取方塊：`[☑] 🎲 志願排定後，剩餘可請假空格自動隨機填滿最大化（兼顧每人平假日休假均衡）`。
   - 階段 1（例假日平衡）：尚有可請假餘額之週六、日與國定假日，優先隨機指派給「目前假日休假數最少」的合格同仁。
   - 階段 2（平常日平衡）：尚有可請假餘額之平日，優先隨機指派給「全月總休假數最少」的合格同仁。
   - 補填假別一律指派【C 超勤加班補休】。
3. **加休 G 提醒機制**：
   - 系統不強制代填 G，由同仁於排定休假中自行挑選 3 天改填【G】加休。
   - 仲裁成果面板提供即時分攤對照表，列出每人「假日休 / 平日休 / 總休天數 / 本次補填 / G假進度」，並持續以紅字提醒缺額。
4. **恪守防呆底線**：
   - 勤二休二輪休 (A) 不更動。
   - 全大隊在勤人數嚴格 `>= 4` 人。
   - 大隊幕僚在勤人數嚴格 `>= 3` 人。
   - 合格安全官在勤嚴格 `>= 1` 人。
