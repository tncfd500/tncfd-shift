# 發布到GitHub.bat 亂碼解析與修正

## 1. 截圖問題分析
從您上傳的截圖可明確看出：
- Windows 命令提示字元預設是以繁體中文（Big5 / CP950）解析 `.bat` 檔案。
- 舊版 `.bat` 使用了 UTF-8 中文檔名與中文字串，CMD 解析時將中文字節切割成亂碼（例如 `'es'`、`'n'`、`'?Pages?'`），導致把文字內容誤當成系統命令執行，直接跳過 `git push` 指令。

## 2. 修正措施
已將 `發布到GitHub.bat` 改寫為純英文字符（ANSI / ASCII 編碼），徹底消除所有編碼相容性錯誤：
1. 執行 `git add index.html README.md notes`
2. 執行 `git commit -m "feat: update shift system"`
3. 執行 `git push origin main`（若有彈出 GitHub 登入視窗，直接在瀏覽器點 Authorize 即可）
4. 成功後顯示 `SUCCESS! Upload completed.`

## 3. 操作指引
請再次雙點擊 `發布到GitHub.bat`，即可順利執行上傳！
